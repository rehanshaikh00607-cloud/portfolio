### Flexbox Quest — Mini Game UI
A responsive mini game dashboard demonstrating Flexbox for its header, game scene, controls, inventory, quest panel, and Flexbox Lab display examples. It uses only HTML and CSS, with no JavaScript, Grid, positioning, or framework.

- [Open Project 2](projects/flexbox-quest/index.html)

## Run and rebuild

Open `index.html` to view the portfolio. Its compiled `tailwind.css` is included, so no build tools are needed just to view the site.

The two lab projects are standalone. Open their linked HTML pages directly in a browser. Flexbox Quest loads its separate `style.css` file.

If you edit Tailwind utility classes in the portfolio, install the dev dependencies and run `npm run build` to regenerate `tailwind.css`.

## Builders Day presentation notes

- **Design:** A dark adventure-game dashboard with gold accents.
- **Flexbox:** Header groups, player and star row, platforms, control pad, inventory, quest rows, and footer.
- **Display values:** The Flexbox Lab section demonstrates block, inline, inline-block, and flex.
- **Responsive design:** Media queries adapt the header and panels for tablet and mobile layouts.
- **Interaction:** Buttons and inventory cards have simple CSS hover feedback.
- **AI use:** AI helped draft and refine the HTML and CSS. Be ready to explain the layout and styles in your own words.
